# emit-txn

Reserves one emission slot (`etxn_reserve(1)`), builds a Payment
transaction with its own `Payment` template (declared in `src/lib.rs` via
`hooks_lib::txn_template!`; 1 drop to the sender of the originating
transaction), and `emit()`s the result. Also exports `cbak`, called when
the emitted transaction settles.

`Payment` is a byte-exact, self-contained template of the *entire*
wire-format Payment transaction — not a minimal pre-image handed to the
undocumented `prepare()` Hook API function. See the doc comment at the top
of `src/lib.rs` for the full field layout and its provenance (derived from
xahaud's own C hook toolchain), and `hooks_lib::txn` (`txn_template!` and
the `txn::codec` primitives it's built from) for how the template itself is
generated. The template lives in this crate, not in `hooks-lib`: any hook
can declare its own transaction shape with `txn_template!` without needing
a `hooks-lib` release.

## Build

```sh
cargo run -p hooks-build -- build --manifest-path examples/emit-txn/Cargo.toml
```

No extra flags needed — this example is deliberately structured so no
compiler-generated loop exists:

- the `Payment` template **is a `static`**, so its const-initialized bytes
  live in a wasm data segment instead of being materialized by a chain of
  store instructions into a stack buffer at runtime, and it doubles as the
  buffer `Payment::prepare_for_emit` (generated by `txn_template!` because
  `Payment` declares all six required emit fields plus `emit_details` — see
  `hooks_lib::txn`) fills in place — there is no separate output buffer to
  zero-initialize.

This static-buffer idiom is the recommended pattern for any hook with
templates or large buffers: it shrinks the binary, cuts the worst-case
instruction count, and avoids needing `--auto-guard` for loops the author
never wrote. The static is a `HookStatic` (hooks-lib): `take()` yields its
one exclusive `&'static mut` safely — no `unsafe` in the hook — with
exclusivity guaranteed by a take-once flag (sound because hooks are
single-threaded and every invocation runs in a fresh wasm instance; see
`hooks_lib::static_cell`).

## Error codes

`EmitTxnError` (`hooks_lib::hook_errors!`, see `src/lib.rs`) is the
`rollback!` code for each failure this hook can exit with:

| variant | code | meaning |
|---|---|---|
| `ReserveFailed` | 1 | `etxn_reserve(1)` failed to reserve an emission slot |
| `CouldNotReadSender` | 2 | `otxn_field(sfAccount)` did not return a 20-byte `AccountId` |
| `BufferAlreadyTaken` | 3 | the static `Payment` buffer had already been `take()`n |
| `SetAmountFailed` | 4 | `Payment::set_amount` failed to set the 1-drop amount field |
| `PrepareFailed` | 5 | `Payment::prepare_for_emit` failed to fill in the host-supplied fields |
| `InvalidPreparedLength` | 6 | `prepare_for_emit` returned a length outside the template's buffer |
| `EmitFailed` | 7 | `emit_buf` failed to submit the prepared transaction |
